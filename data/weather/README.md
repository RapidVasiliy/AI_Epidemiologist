# Недельная погода

`<город>_weekly.csv` — недельные температура и влажность для `--weather-weekly`, получены
`scripts/convert_weather_export.py` из архива срочных наблюдений метеостанций.

| Файл | Источник | Период |
|---|---|---|
| `spb_weekly.csv` | метеостанция Санкт-Петербург (WMO 26063), архив rp5.ru | 28.12.2009 – 25.11.2024 |

Данные предоставлены сайтом «Расписание Погоды», rp5.ru (по условиям сайта источник указывается при использовании).
