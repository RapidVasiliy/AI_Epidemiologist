# RSCF_Uncertainty: что там есть и что полезно проекту

Репозиторий: https://github.com/vnleonenko/RSCF_Uncertainty (коммит `6542978`). Разбор выполнен
по локальной копии; данные и код в проект не копировались, кроме того, что перечислено в разделе
«Что уже использовано».

## Состав

| Каталог | Содержимое |
|---|---|
| `BaroyanAgeMultistrain_v2/` | обобщённая модель Барояна–Рвачёва: возрастные группы × штаммы, матрица контактов; калибровка (отжиг + L-BFGS), бутстреп-неопределённость, прогноз по неполным данным, визуализация R_t и популяционного иммунитета, дашборд Dash |
| `generateIncidence/` | `generateIncidence.py`, `loadPCRRes.py`, `detectAndFixDFRow.py` (те же, что прислал автор) и исходные xlsx по городам |
| `Coronavirus_model/` | модель COVID-19 для СПб (логистическая кривая, траектории с бутстрепом) |
| `multistrain.pdf`, `multiage.pdf` | описания моделей |

## Данные

1. **Общероссийская недельная выгрузка за сезон 2017/18** (`generateIncidence/input/export_EPI_MAIN_weekly_201740_201839.xlsx`,
   `export_LABD_PCR_weekly_201740_201839.xlsx`), 52 недели:
   - 61 город: ОРВИ, гриппоподобные заболевания (ILI) и госпитализации с ОРВИ (ARIH) по группам 0–2, 3–6, 7–14, 15–64, 65+;
   - 55 городов: ПЦР **по возрастам** (0–2, 3–6, 7–14, 15+): число протестированных и положительных на A без подтипа,
     A(H1N1)pdm09, A(H3N2), B, а также на парагрипп, аденовирус, РС-вирус, риновирус, коронавирусы, метапневмовирус,
     бокавирус и SARS-CoV-2 (столбцы `NC_*`).

   **Главный вывод по этим данным:** доля положительных на грипп сильно зависит от возраста. За недели 40/2017–20/2018
   по всем городам: 0–2 года — 0.09, 3–6 — 0.18, 7–14 — 0.15, 15+ — 0.21 (СПб: 0.17 / 0.28 / 0.22 / 0.33); за все
   52 недели выгрузки, с межсезоньем, — 0.07 / 0.14 / 0.12 / 0.17. Допущение «доля гриппа среди ОРВИ одинакова во всех
   возрастах», на котором построены и ряды `generateIncidence.py`, и наш `ai4epi.data.age_groups`, завышает
   заболеваемость гриппом детей 0–2 лет примерно вдвое и занижает её у взрослых. Для групп 0–14 / 15+ эффект меньше
   (дети 3–14 лет ближе к взрослым): доля детей в гриппе сезона в СПб 0.54 → 0.48, см. `docs/age_groups.md`.

2. **Исходные xlsx по городам** (`generateIncidence/input/Заб <город>.xlsx`, `ПЦР <город>.xlsx`): Москва, СПб
   (1990–2020), Новосибирск, Омск, Воронеж, Краснодар — ОРВИ по возрастам и ПЦР по подтипам. Это те же источники, что
   и наши `data/regions/*`, но в «сыром» формате (многоуровневый заголовок, в некоторых файлах столбцы `3-Jun`/`Jul-14`
   вместо `3 - 6`/`7 - 14`, см. `generateIncidence/readme.txt`). Конвертер в формат `ai4epi.data.local_excel` позволит
   добавить в проект Москву, Новосибирск, Омск, Воронеж и Краснодар.

3. **Ряды «возраст × штамм» для СПб** (`BaroyanAgeMultistrain_v2/data/input/incidence_strains_spb_{2,4}_age_groups.csv`).

4. **Матрицы контактов** для 2 и 4 возрастных групп (`contact_matrix_{2,4}_age_groups.p`), например для 0–14 / 15+:
   `[[8.56, 5.88], [0.55, 4.66]]`. Это ровно то, чего не хватает нашей возрастной модели: с внешней матрицей вместо
   четырёх свободных коэффициентов остаётся один масштабный множитель, и проблема неидентифицируемости матрицы
   (R-hat 2.7–3.3, см. `docs/age_groups.md`) снимается.

5. `populations.txt` — численность населения 49 городов; `request_for_bulletin_*.json` — формат выгрузки параметров и
   данных из дашборда для бюллетеня.

## Код: что полезно

| Что | Где | Польза для проекта |
|---|---|---|
| бутстреп с усечённым отрицательно-биномиальным шумом | `bootstrapping/error_structures.py`, `bootstrap_executor.py` | альтернатива нашей ABC/MCMC с ε = 1: дисперсия шума оценивается по остаткам, пучок траекторий получается шире и честнее (наша проблема — узкий пучок, `docs/review.md`, 2.3) |
| R_t и популяционный иммунитет по траектории модели | `models/BR_model_new.py`, `visualization/bootstrap_results.py` | дополнительные показатели в блок `mechanistic_wave` и секцию отчёта |
| прогноз по неполной волне с перебором сдвига пика (−3…0 нед.) и «воротами» прогноза | `base_optimizer.run_prediction`, `bootstrapping/predict_gates.py` | готовая постановка для ранней фазы роста, где у нас `early_phase_caution` |
| общая модель «возраст × штамм» с матрицей контактов | `models/BR_model_new.py` | обобщение нашей `AgeGroupBRModel` на штаммы; удобно сверять реализации |
| дашборд ручной калибровки (Dash) | `gui/` | инструмент для эпидемиологов; в проект — только при запросе |

## Код: ограничения (общие с v4b)

Те же особенности, что разобраны на `BaroyanMultistrain_v4b` (`research/multistrain_calibration/README.md`):
«отжиг» в `simulated_annealing.py` на каждом шаге берёт случайную точку во всём диапазоне (по сути — случайный поиск),
затем L-BFGS по ступенчатой целевой функции; данные проходят через `dropna()` (ряд сжимается во времени); μ задаётся
(`percent_protected`), а не оценивается. Сдвиг штаммов по времени задан вручную в коде модели
(`strain_shift = [[0], [10], [0]]`), а не калибруется.

## Что не относится к проекту

`Coronavirus_model/` (COVID-19 в СПб, логистическая кривая) к бюллетеню по гриппу не относится.

## Что уже использовано

| Что | Где в проекте |
|---|---|
| исходные xlsx Москвы, Новосибирска, Омска, Воронежа, Краснодара → `data/regions/<город>` | `ai4epi.data.raw_regions`, `scripts/convert_raw_regions.py`; ряды гриппа совпадают с `incidence_strains_*.csv` (корреляция ≥ 0.9997) |
| ПЦР по возрастам (сезон 2017/18, 55 городов) → `data/national/age_pcr_2017w40_2018w39.csv` | `ai4epi.data.age_pcr`; возрастные ряды строятся по возрастной доле положительных (`docs/age_groups.md`) |
| матрица контактов 0–14 / 15+ | `RSCF_CONTACT_MATRIX_2` в `ai4epi.mechanistic.models`; возрастная модель БР с одним масштабным множителем (`docs/age_groups.md`) |
| бутстреп с отрицательно-биномиальным шумом | `calibrate(method="bootstrap")`, `--br-method bootstrap` (`docs/mechanistic_wave.md`) |
| R_t по траектории модели | блок `mechanistic_wave.reproduction_number`, нижняя панель рис. 5 |
| модель v2 «возраст × штамм» | `research/multistrain_calibration/brmodel.py` (порт, сверка с исходником) |

Не перенесены: прогноз по неполной волне с перебором сдвига пика (`predict_gates`), дашборд Dash, популяционный
иммунитет как отдельный показатель.
